# 結婚式招待状メーカー

ゲストの名前・住所とデザインを入れると、**印刷所に入稿できる CMYK の PDF** を作る Web アプリです。
Rust で書いて WebAssembly にコンパイルしてあり、**処理はすべてブラウザの中で行います**(サーバー不要。入力した名簿は外部に送信されません)。

## できること

- **7 種類のデザイン**: クラシック(デフォルト)/ボタニカル/桜/モダン/睦月(一月: 紅白の梅・松・金の水引)/雪(冬: 銀鼠の地に雪輪文様)/ホワイト(紙の白にグレーの線画の花)
- **招待状カード**: 105×148mm(A6)。ゲストごとに「〇〇 様」を入れて 1 名 1 ページで出力
  - **レイアウトを 3 種類から選べる**(デザインの色・飾りとは別に組み合わせられる):
    横書き(標準)/縦書き(宛名・挨拶文・差出日・名前を縦組み、日時と会場は下段に横組み)/写真入り(上部に二人の写真)
  - 本文、日時、会場、返信期日を自動でレイアウト(入りきらないときは文字を自動で縮小)
  - 時候の挨拶 `{時候}` と「〇年〇月吉日」は挙式日から自動で入る
- **封筒(洋形2号 114×162mm)**: 縦書きの宛名。番地は漢数字に変換、連名にも対応(敬称の高さを揃える)、裏面に差出人
- **案内図(ハガキ 縦 100×148mm / 横 148×100mm)**: 地図の画像、交通手段ごとの行き方(電車・地下鉄・バス・タクシー・お車・駐車場・徒歩・飛行機のアイコン付き)、
  最寄り駅からの道順写真(最大 6 枚、番号と矢印付き。見出しは「南海なんば駅からの道順」などに変えられる)、補足を入れられる。地図と道順写真の両方があれば表裏 2 ページ
  (表: 地図・交通手段、裏: 道順写真)。横向きでは地図と交通手段(地図がなければ交通手段と道順写真)を左右に並べる。写真は撮影時の向きを反映し、透明部分は白にして CMYK に変換する。
  デザインは招待状と同じか、7 種類から案内図だけ別に選べる(背景と飾りも付く。下の飾りに本文が重ならないよう余白をとる)
- **楽曲管理(別ページ `music.html`)**: 使うシーン・楽曲名・発注状況(選定中 → 決定 → 発注済み → 納品済み)・発注先を管理し、
  進み具合を帯グラフと発注先ごとの件数で表示。選定中は楽曲の候補を複数持て、「決定」で 1 曲に絞る。JSON で読み込み・書き出し
- **Excel(xlsx)でまとめて入力**: デザイン・挙式情報・出力の設定・ゲスト名簿を 1 つの xlsx に書き出し、
  編集して読み込むと画面の入力がすべて復元される(下記「Excel テンプレート」)
- **ゲスト名簿は One-W の「出席者名簿」形式**で読み込み・書き出し(xlsx / CSV)。
  住所2 の番地と建物名は自動で分けて宛名に使い、肩書き・ふりがな・出欠などの列も書き出し時にそのまま残す
- CSV は UTF-8 と Excel の Shift_JIS のどちらでも読める(書き出しは BOM 付き UTF-8)
- プレビュー(SVG)を見ながら編集でき、入力内容はブラウザに保存される

## 入稿データの仕様

| 項目 | 内容 |
| --- | --- |
| 色空間 | すべて DeviceCMYK(`k`/`K` オペレータのみ。RGB・グレー・透明効果は使っていない) |
| 写真 | 案内図の写真は CMYK の JPEG(DCTDecode / DeviceCMYK)で埋め込み。透明(SMask)は使わない。RGB からは墨版を最大にとる簡易変換(総インキ量は必ず 300% 以下) |
| フォント | しっぽり明朝 / Great Vibes を TrueType のサブセットとして埋め込み(ToUnicode 付き) |
| 塗り足し | 招待状カード・案内図は各辺 3mm |
| トンボ | 日本式トンボ(内トンボ・外トンボ・センタートンボ)。オン/オフ切り替え可 |
| ページボックス | MediaBox / TrimBox / BleedBox を設定済み |

小さい文字は K のみ、またはそれに近い少ない版で刷るようにし、総インキ量は 300% 以下に抑えています。
写真の色を厳密に合わせたい場合は、印刷所の ICC プロファイルで変換した画像を使うか、入稿先に相談してください。
封筒は既製の封筒に印刷する想定なので、塗り足しなしの仕上がりサイズで出力します。

> ICC プロファイル(OutputIntent)は入れていないため、PDF/X-1a の規格には準拠していません。
> 印刷所によっては PDF/X での入稿を求められることがあるので、入稿先の規定を確認してください。

## ビルドと起動

```bash
rustup target add wasm32-unknown-unknown
cargo install wasm-bindgen-cli --version 0.2.129   # Cargo.toml の wasm-bindgen と同じ版
./build.sh                                          # www/pkg に wasm を出力
python3 -m http.server -d www 8000                  # http://localhost:8000 を開く
```

`www/` は静的ファイルだけなので、GitHub Pages などにそのまま置けます。
`.github/workflows/pages.yml` は main への push でテストとビルドを行い、GitHub Pages に公開します
(リポジトリの Settings → Pages で Source を「GitHub Actions」にしてください)。

## テスト

```bash
cargo test
cargo run --example sample -- target/samples   # 全デザインのサンプル PDF / SVG を書き出す
```

テストでは出力した PDF を読み直し、CMYK 以外の色の指定や透明効果が含まれていないこと、写真が DeviceCMYK の JPEG であること、
フォントが埋め込まれていること、MediaBox / TrimBox / BleedBox の値を確かめています。

## 構成

| --- | --- |
| `src/canvas.rs` | 描画命令(ディスプレイリスト)。色は `Cmyk` 型だけ |
| `src/pdf.rs` | ディスプレイリスト → 入稿用 PDF(pdf-writer + subsetter) |
| `src/svg.rs` | ディスプレイリスト → 画面プレビュー用 SVG |
| `src/layout.rs` | 招待状カード・封筒のレイアウト、トンボ |
| `src/designs.rs` | デザイン定義 |
| `src/typeset.rs` | 禁則つき折り返し・縦書き |
| `src/access.rs` | 案内図(ハガキ)のレイアウトと交通手段のアイコン |
| `src/photos.rs` | 案内図の写真の保管と RGB → CMYK 変換 |
| `src/music.rs` | 楽曲管理の JSON の読み込み・整形・集計 |
| `src/xlsx.rs` | Excel テンプレートの書き出しと読み込み |
| `src/roster.rs` | ゲスト名簿の表(One-W 形式・簡易形式)の読み書き |
| `src/model.rs` / `src/csv.rs` / `src/zip.rs` | 入力データ、CSV 読み込み、ZIP の読み書き |
| `src/lib.rs` | JavaScript から呼ぶ API(wasm-bindgen) |
| `www/` | 画面(`index.html` 招待状・案内図、`music.html` 楽曲管理)とフォント |

## Excel テンプレート

画面の「Excel テンプレートをダウンロード」で、今の入力内容が入った `wedding_invitation.xlsx` を書き出せます。

| シート | 内容 |
| --- | --- |
| 設定 | A 列が項目名、B 列が値。デザイン(プルダウン)、招待状のレイアウト(横書き/縦書き/写真入り)、新郎新婦のお名前、挙式日、受付開始・挙式・披露宴の時刻、返信期日、差出日の表記、会場名・住所・電話番号、本文(セル内改行可)、差出人の郵便番号・住所、トンボ・封筒の裏面(する/しない) |
| 出席者名簿 | One-W の出席者名簿と同じ 32 列(姓・名・肩書き・外字ファイル名・ふりがな・敬称・区分・〒・住所1・住所2・…・特記事項)。2 行目以降が 1 名ずつ。連名を入れたゲストがいるときだけ末尾に「連名」列を付ける |

- 項目名や見出しで対応を取るので、行や列の順番を入れ替えても読み込めます
- Excel が日付・時刻・数値に変換したセル(例: `2027/4/10`、`10:30`、先頭の 0 が消えた郵便番号)も元に戻して取り込みます
- 読み取れなかった値は画面に注意として表示します

| アクセス | 案内図の交通手段(種類はプルダウン、説明)。案内図のデザイン・向き・タイトル・補足は「設定」シート。写真は Excel には入らない(画面で追加) |

- One-W から書き出した名簿だけの xlsx(「設定」シートなし)を読み込むと、ゲスト一覧だけを置き換えます

## 楽曲管理の JSON

画面の「JSON を書き出す」で次の形式のファイルになります(手で編集して読み込むこともできます)。

```json
{
  "version": 1,
  "songs": [
    { "scene": "新郎新婦入場", "titles": ["候補 A", "候補 B"], "status": "選定中", "vendor": "" },
    { "scene": "乾杯", "titles": ["曲名"], "status": "発注済み", "vendor": "会場" }
  ]
}
```

- `status` は `選定中` / `決定` / `発注済み` / `納品済み`。`selecting` / `decided` / `ordered` / `delivered` や「発注済」「完了」なども読み込めます
- `titles` は選定中なら候補を複数、それ以外は 1 曲。`"曲A / 曲B"` のような 1 行の書き方や、`title` / `楽曲名`・`scene` / `使うシーン`・`vendor` / `発注先` といった項目名も読み込めます
- 選定中以外で曲が複数あるときは 1 曲目を残し、画面に注意を出します

## ゲスト名簿(One-W 形式)

ゲスト欄の「名簿を読み込む」で One-W の出席者名簿(xlsx / CSV)を読み込み、「One-W 形式で書き出す」で同じ形式に戻せます。

- 見出し行に「姓」「名」があれば One-W 形式として読み込みます。宛名には姓・名・敬称・〒・住所1・住所2 を使います
- 住所2 は番地と建物名に分けます(改行があればそこで、なければ番地の数字・ハイフン・丁目番地号が途切れたところで)。
  例: `2-15-3 アドニス406号` → 住所「…2-15-3」+ 建物名「アドニス406号」
- 敬称が空欄のゲストは、印刷では「様」を使い、名簿には空欄のまま残します
- 先頭の 0 が消えた 6 桁の郵便番号は 0 を補います
- 読み込んだ住所を画面で変えていなければ、書き出しでは元の住所1・住所2 をそのまま出します

以前の簡易形式(見出し `氏名,郵便番号,住所1,住所2,連名,敬称`)の CSV も引き続き読み込めます。
